# Workshop de 1 hora — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adaptar a apresentação (`index.html`) para um workshop online de 60 minutos com laboratório no Copilot CLI e criar os materiais do participante.

**Architecture:** Tudo continua num único `index.html`. As tarefas reordenam as `<section class="slide">` existentes pelo `id`, inserem slides novos em pontos fixos, e acrescentam CSS antes do marcador `      /* === fim dos componentes === */`. Os materiais do participante são dois arquivos Markdown em `workshop/`.

**Tech Stack:** HTML/CSS/JS puro; Python 3 (só para os scripts de edição); Google Chrome headless para capturas de tela.

**Spec:** `docs/superpowers/specs/2026-09-18-workshop-1h-design.md`

**Verificação:** por decisão do usuário, não há testes automatizados. Cada tarefa termina com capturas de tela dos slides que mudaram, conferidas visualmente: nenhum texto cortado, sobreposto ou encostado no contador do rodapé.

## Convenções

- Rodar tudo a partir de `/Users/regis/develop/stef/apresentacao`.
- **Captura de tela de um slide** (substitua `N` pelo número do slide e `NOME` pelo arquivo):

```bash
S=/tmp/shots; mkdir -p $S; C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
f=$S/NOME.png; rm -f $f
"$C" --headless=new --disable-gpu --hide-scrollbars --window-size=1920,1080 \
  --virtual-time-budget=5000 --screenshot=$f "file://$PWD/index.html#N" >/dev/null 2>&1 & pid=$!
for i in $(seq 1 40); do [ -s "$f" ] && break; sleep 0.5; done; kill $pid 2>/dev/null
```

O Chrome às vezes não encerra sozinho depois da captura; o laço espera o arquivo e encerra o processo.

- **Listar a ordem dos slides:**

```bash
grep -o '<section class="slide[^>]*aria-label="[^"]*"' index.html | sed 's/.*aria-label=//' | nl
```

````markdown
# Workshop Superpowers — pré-requisitos

Faça isto **antes** do workshop. No dia não haverá tempo para instalação: vamos direto

```bash
node --version

| Sistema | Comando |

```bash
copilot plugin marketplace add obra/superpowers-marketplace
copilot plugin install superpowers@superpowers-marketplace

primeiro build baixa dependências e pode levar mais de 15 minutos.

## 5. No dia
````

````markdown
## Etapa 2 · O plano (5 min)

Na mesma sessão:

```text
Use a skill /writing-plans para criar o plano de implementação a partir do design
aprovado. Tarefas pequenas, com o teste antes do código em cada uma.
```

Leia o plano. Se algo sair do recorte da sua stack, peça para cortar.

**Checkpoint no chat:** quantas tarefas o seu plano tem.

## Etapa 3 · Primeira tarefa com TDD (10 min)

```text
Execute somente a Tarefa 1 do plano usando a skill /test-driven-development.
Mostre o teste falhando antes de implementar. Faça commit local e não faça push.
```

Confira: o teste falha primeiro (vermelho), depois passa (verde). Revise com `git diff`.

Para rodar os testes você mesmo:

| Stack | Mac | Windows |
|---|---|---|
| iOS | `xcodebuild test -project app_demo/portabilityDemo.xcodeproj -scheme portabilityDemo -destination 'platform=iOS Simulator,name=iPhone 16'` | — (só Mac) |
| Android | `cd project && ./gradlew :portability:testDebugUnitTest` | `cd project; .\gradlew.bat :portability:testDebugUnitTest` |
| Backend | `./mvnw test -Dtest=InstitutionServiceTest` | `.\mvnw.cmd test "-Dtest=InstitutionServiceTest"` |

**Checkpoint no chat:** a saída do teste passando.
````
